# Десктопное приложение: Фотопринт · AI-Ассистент (Tauri 2 + React + Bun)

Приложение разработано для компании **ООО «Фотопринт»** в рамках Трека 3 хакатона.

Проект создан с помощью `bun create tauri-app` (Tauri 2.0 + React 19 + TypeScript + Tailwind CSS).

---

## 🚀 Быстрый запуск

### 1. Веб-режим (мгновенный запуск UI):
```bash
cd desktop
bun run dev
```
Интерфейс откроется по адресу: `http://localhost:1420`.

### 2. Запуск нативного десктопного окна (Tauri):
```bash
cd desktop
bun run tauri dev
```

### 3. Сборка продакшн-бандла:
```bash
cd desktop
bun run build
```

## 🛠️ Реализованный функционал (Автономный режим / 0 запросов в сеть)

Приложение полностью готово к демонстрации всех обязательных сценариев ТЗ без внешнего бэкенда:

1. **Шапка и ролевая модель (RBAC ОТ-02)**:
   - Быстрый переключатель между тремя ролями:
     - `Генеральный директор` (Полный доступ, видит финансы и стратегию);
     - `Начальник производства` (Доступ к техкартам, станкам, браку);
     - `Клиентский сервис PicPac` (Доступ к SLA, тикетам, возвратам).
   - Кнопка **«Сброс демо»** (возвращает задачи, расшифровки и логи к исходному состоянию).

2. **Встречи и протоколы (Сценарии 1, 2, 3, 4)**:
   - **Draft & Review (AI-03 / AI-04)**: выбор из 3 контрольных расшифровок или вставка своего текста с таймкодами. Модель структурирует результат: «Решено», «Предложено», «Обсуждалось», «Требует уточнения», «Риски».
   - Интерактивные карточки согласования задач: возможность отредактировать исполнителя, срок и текст прямо перед фиксацией.
   - Подтверждение («Подтвердить и внести в реестр») переводит задачи в активный реестр и пишет событие в аудит.
   - Подготовка повестки и свободных слотов календаря.

3. **База регламентов и RAG (Сценарий 5)**:
   - 20 встроенных корпоративных документов с тремя уровнями допуска.
   - **Проверка RBAC**: если начальник производства спрашивает про бюджет или оклады директоров — выводится красный баннер **ДОСТУП ЗАПРЕЩЕН**, а факт попытки пишется в аудит-лог. Если тот же вопрос задает директор — полный ответ с цитатами.
   - **Антигаллюцинация (AI-05)**: при отсутствии фактов система отвечает «Требует уточнения / данные отсутствуют».
   - **Защита от Prompt Injection**: попытки взлома промпта изолируются и игнорируются.

4. **Управленческий пульс (KPI) (Сценарий 6)**:
   - Сводка от AI, 6 виджетов метрик (ERP, CRM, 1C) со статусами (норма, внимание, критично) и динамикой.
   - Реестр критических отклонений и просроченных решений.

5. **Реестр поручений**:
   - Полный список задач, фильтрация по статусам (В работе, Выполнено, Просрочено), чекбоксы выполнения, привязка к совещаниям.

6. **Журнал аудита (ОТ-04, AI-06)**:
   - Таблица событий безопасности в реальном времени с фильтрацией по результату (SUCCESS, ACCESS_DENIED, REJECTED).
