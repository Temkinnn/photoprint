# AI & RAG Контур (Разработчик 2)

Данная папка полностью изолирована для работы Разработчика 2 (AI / NLP / RAG Engineer).
Все скрипты, промпты, распознавание речи и RAG находятся здесь, исключая любые конфликты Git с бэкендом (`backend/`) и фронтендом (`desktop/`).

---

## Структура файлов:

- `pipeline_meeting.py` — полный рабочий контур:
  1. Запись живого голоса с микрофона в `meeting.wav`;
  2. Локальное распознавание речи через `faster-whisper` с таймкодами;
  3. Извлечение поручений, решений, рисков и вопросов через локальный `Qwen 2.5:7b` (Ollama);
  4. Создание корпоративного Word-протокола с **жёлтой подсветкой** ключевых мест и маркой `требует уточнения` (AI-04, AI-05).
- `test_meeting_ai.py` — быстрый тест извлечения задач из текстовой стенограммы.
- `requirements.txt` — зависимости Python для AI-модуля.

---

## Быстрый запуск в VS Code:

1. **Установка зависимостей (один раз)**:
   ```powershell
   pip install -r ai/requirements.txt
   ```

2. **Запуск полного пайплайна (Голос -> Whisper -> Qwen -> Word)**:
   ```powershell
   python ai/pipeline_meeting.py
   ```

3. **Быстрый тест модели Qwen 2.5 без микрофона**:
   ```powershell
   python ai/test_meeting_ai.py
   ```
